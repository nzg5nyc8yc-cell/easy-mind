MindMap Studio 사용법

  • 노드 생성: 상단의 ‘노드’ 버튼 또는 N. 현재 보이는 화면 중앙에 생성됩니다.
  • 이미지 노드: 상단의 ‘이미지’ 버튼으로 사진을 불러오면 화면 중앙에 이미지 노드가 생성됩니다. 이미지 전체가 잘리지 않도록 노드 안에 자동 맞춤됩니다.
  • 이름 변경: 일반 노드는 제목을 더블클릭해 입력하고, 이미지 노드는 더블클릭 후 이름을 입력합니다.
  • 노드 이동: 노드를 마우스로 끌어 이동합니다.
  • 블록 지정: 상단 ‘블록지정’ 또는 B → 빈 작업영역을 드래그해 여러 노드·화살표를 선택합니다. 선택 후 점선으로 표시되는 선택영역을 끌면 노드·이미지가 함께 이동합니다. Delete 또는 선택영역 우클릭으로 함께 삭제할 수 있으며, 액션 뒤에는 블록 선택이 자동 해제됩니다.
  • 크기 변경: 노드를 선택한 뒤 오른쪽 아래의 파란 손잡이를 드래그합니다. 일반 노드와 이미지 노드 모두 가로·세로를 자유롭게 조절할 수 있습니다.
  • 화살표 생성: ‘화살표’ 버튼 → 시작 노드 → 도착 노드 순서로 클릭합니다.
  • 상세 정보: 노드를 선택한 뒤 오른쪽에서 설명, 담당자, 상태, 날짜, 태그 등을 입력합니다.
  • 삭제: 노드 또는 화살표를 우클릭하고 ‘삭제’를 선택합니다. 선택 후 Delete도 가능합니다.
  • 프로젝트 페이지: 상단 탭의 + 버튼으로 페이지를 추가합니다. 탭을 더블클릭하면 프로젝트 이름을 바꿀 수 있습니다.
  • 교차선 회피: 화살표 교차 부분은 자동으로 점프 모양으로 표시됩니다.
  • 이동/확대: 빈 배경을 드래그해 이동하고 마우스 휠로 확대/축소합니다.
  • 저장: 브라우저에 자동 저장되며, ‘저장’ 버튼으로 JSON 파일을 내려받을 수 있습니다.
